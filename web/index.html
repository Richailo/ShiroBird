Wazuh integration

Read ShiroBird's local JSONL using a Wazuh agent on the server.

Install and enroll Wazuh Agent on this Linux server first. Then use the prepared localfile integration without changing NetBird.

<localfile>
  <log_format>json</log_format>
  <location>/path/to/ShiroBird/data/siem/events.jsonl</location>
</localfile>

For a safe, idempotent configuration after the agent has been installed:

bash scripts/configure-wazuh-agent.sh

Restart the Wazuh agent after configuration. Confirm ingestion in Wazuh separately: ShiroBird cannot verify delivery automatically.

Syslog forwarding

Send ShiroBird flow events as RFC 5424-style UDP Syslog to a receiver.

UDP is not encrypted and has no delivery acknowledgement. Use only a trusted network or encrypted VPN. A successful test verifies local sending, not ingestion by the remote SIEM.
